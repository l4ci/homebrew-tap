# l4ci/homebrew-tap

Homebrew formulae and casks for tools by l4ci.

```sh
brew tap l4ci/tap
```

| Name | Type | Install | Description |
|---|---|---|---|
| [rota](https://github.com/l4ci/rota) | formula (macOS, Linux) | `brew install l4ci/tap/rota` | Plan, ship and run parallel rounds with AI coding agents |
| [MocoCompanion](https://github.com/l4ci/MocoCompanion) | cask (macOS) | `brew install --cask l4ci/tap/mococompanion` | Menubar companion for Moco time tracking |

After installing rota, install its agent skills:

```sh
rota skills install
```

## Updates

```sh
brew update && brew upgrade
```

`Formula/rota.rb` is generated by each rota release (goreleaser). Don't edit it by hand, because the next release overwrites it.
